# Fly Island Custom v0.3.0

首个独立衍生发布，基于 flyl1u/fly-island（MIT），监测/额度设计参考 MoFeng2223/BrimDeck（Apache-2.0）。保留相关来源和第三方许可证。

- CPU、内存、GPU、网速及进程排行；GPU 使用实际设备名称和设备标识，避免编号混淆。
- Codex / Claude 额度分别开关，支持全部隐藏；默认开启 Codex。
- DeepSeek 或自定义 OpenAI 兼容翻译服务，支持自选模型及无密钥本机 / 明确开启的私有局域网 HTTP。
- 移除上游更新及推广入口，从本仓库手动更新。

Windows 10 / 11 x64，需 WebView2 Runtime。EXE 和 MSI 二选一；未使用 Authenticode 代码签名，可能提示未知发布者。使用 SHA256SUMS.txt 校验下载；法律声明在安装包及单独压缩包中提供。

限制：额度接口可能变更失效，不含本地 Token / 费用估算，真实 Claude 账号尚未验证。GPU 取决于驱动和性能计数器。沿用原应用标识以兼容本机数据，请避免与原版并行安装/运行，升级前备份重要数据。
