# 性能、额度与自定义翻译

## 性能监测

展开岛屿，点击右上方的波形图标。面板显示 CPU 总占用和各逻辑处理器、内存已用/总量、GPU 占用、网速及应用排行。

- GPU 列表来自 DXGI 设备枚举，以显卡实际名称显示，不使用自定义 GPU 编号，也不声称对应任务管理器编号。同名设备附加设备标识区分；Windows 软件渲染适配器不显示。性能计数器按设备标识对应到显卡，同一显卡的进程、引擎和内部节点不会产生额外选项。仅列出已取得有效 GPU 性能读数的设备，不将没有性能读数的间接或虚拟适配器当成额外显卡；休眠设备可能在恢复并产生读数后才出现。已识别设备后续无有效读数时显示「暂无读数」，不会伪造 0%。设备列表每 30 秒重读以适应设备变化。
- 点击 CPU / 内存切换排行，同名进程合并。CPU 按整机百分比归一化。
- 网卡可单独选择。「全部网卡」可能包含 VPN、虚拟交换机等，同一流量经过多个接口时会重复计数，建议选择实际联网网卡。
- 每次采样至少间隔 300 毫秒，面板每轮采样后约一秒刷新。折叠、切页或隐藏到托盘后不再采集；重新打开会重新建立有效采样间隔。

## AI 额度

设置页顶部的「AI 额度监控」分别控制 Codex 和 Claude。默认只开启 Codex，两个都关闭会隐藏仪表图标。此设置与 AI 状态灯独立。

- **Codex**：读取 `CODEX_HOME`（绝对路径）或 `%USERPROFILE%\.codex\auth.json` 中的 ChatGPT 登录状态，仅向 `https://chatgpt.com/backend-api/wham/usage` 查询账号额度。API Key 模式没有对应的订阅额度。
- **Claude**：读取 `CLAUDE_CONFIG_DIR`（绝对路径）或 `%USERPROFILE%\.claude\.credentials.json` 的 Claude Code 订阅登录，仅向 `https://api.anthropic.com/api/oauth/usage` 查询。当前版本不读取 Claude 桌面版的加密登录缓存。
- 返回哪些额度窗口就显示哪些，通常包括五小时和每周额度；不支持的字段不显示为零。
- 仅在额度页展开且窗口可见时查询，自动刷新间隔一分钟。失败时指数退避，尊重有效的 `Retry-After`；手动刷新不会绕过退避。
- 上次成功数据仅缓存在内存，失败时显示「缓存 · 非实时」和读取时间；登录丢失或身份变化时清空缓存。重启后会重新查询。
- 不修改、刷新或退出其他软件的登录；凭据不发给前端、不写入日志或配置文件，不读取/上传对话。请求禁止跟随重定向。
- 这些账号用量接口不属于稳定的公开 API，可能随服务更新而失效。本版显示订阅额度与重置时间，不包含本地 Token 统计或估算费用。

功能设计参考 [BrimDeck](https://github.com/MoFeng2223/BrimDeck)，采集和界面在 Fly Island 的 Rust / React 架构中实现。

## 自定义翻译服务

按 Alt+C，在翻译窗口点击设置，选择「自定义兼容服务」，填写：

1. Base URL，例如 `https://api.example.com/v1`；也接受完整 `/chat/completions` 地址。
2. 服务商提供的模型 ID。
3. API 密钥，点击「保存密钥」。本机兼容服务如 `http://localhost:11434/v1` 可以不填。局域网自建服务请勾选「允许局域网 HTTP（自建服务，可不填密钥）」，同样可以不填密钥。
4. 点击「测试连接」，会发送 `Hello` 的短翻译请求，可能产生少量用量。

协议为非流式 OpenAI 兼容 Chat Completions（`model`、`messages` 和 `choices[].message.content`）。Claude / Gemini 原生协议需要兼容网关。HTTP 默认只允许 localhost、127.0.0.1 或 ::1；启用局域网选项后，也允许 RFC1918 私有 IPv4（10.x、172.16–31.x、192.168.x）及 IPv6 ULA 地址。公网服务仍需使用 HTTPS。地址不能携带用户名、密码或查询参数；请求不跟随重定向。本机及已启用的局域网自建服务直接连接，不经过系统代理。

设置自动保存在本机。密钥按规范化后的完整接口地址分别保存在 Windows 凭据管理器，地址改变后需保存该地址的密钥。原 DeepSeek 密钥和快捷键设置保持兼容。公网请求超时 30 秒，本机及已启用的局域网模型超时 120 秒。

## 开发验证

`pnpm build` 检查前端，`pnpm tauri build --no-bundle` 生成桌面程序。`cargo test --lib -- --test-threads=1`（在 src-tauri 中）包含真实系统采样、本地假服务翻译协议、地址限制与额度解析测试。

运行 `pnpm dev` 后访问 `/tests/monitoring.html` 检查实际应用的面板和开关，`?translation=1` 检查翻译配置，`?quota=cached` 检查缓存提示，`?en=1` 检查英文布局。这些页面使用 Tauri 官方 mock，所有监测/额度数据均为模拟值，不读取真实账号。额度的实际联网测试需显式运行 `cargo test --lib live_codex_quota_smoke -- --ignored`，只执行一次只读请求。
